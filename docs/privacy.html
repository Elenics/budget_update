개인정보처리방침 — 짠소리 가계부

시행일: 2026년 7월 19일 · 앱 패키지 com.sonjisu.budget

핵심 요약 — 이 앱은 이용자의 금융 정보와 개인정보를 개발자 서버나 제3자에게 전송하지 않습니다.
  • 회원가입, 로그인, 계좌·카드 연동이 없습니다.
  • 거래 내역·결제 알림 내용·카테고리 등 모든 데이터는 이용자 기기 내부 저장소에만 저장됩니다.
  • 분석에 쓰는 인공지능(AI) 모델이 기기 안에서 동작합니다(온디바이스). 분석을 위해 데이터를 밖으로 보내지 않습니다.
  • 앱이 인터넷을 쓰는 경우는 내려받기 목적뿐입니다(AI 모델 파일, 예·적금 금리 공시 목록).

1. 처리하는 정보

앱은 아래 정보를 기기 내부에서만 처리합니다. 개발자는 이 정보에 접근할 수 없습니다.

정보처리 목적저장 위치외부 전송
결제·입금 알림 내용(가맹점명, 금액, 시각)가계부 자동 기록기기 내부 앱 저장소하지 않음
이용자가 직접 입력한 거래·메모·예산가계부 기능 제공기기 내부 앱 저장소하지 않음
카테고리 수정 이력자동 분류 정확도 개선(기기 내 학습)기기 내부 앱 저장소하지 않음
음성 입력(선택 기능 사용 시)지출 내용 받아쓰기저장하지 않음(변환 후 폐기)하지 않음

금융과 관련 없는 알림은 저장하지 않고 즉시 폐기합니다.

2. 권한 안내

권한사용 목적거부하면
알림 접근카드 승인·입금 알림을 읽어 자동 기록자동 기록만 동작하지 않으며, 직접 입력으로 사용 가능
알림 표시거래 감지·월간 결산 안내알림만 표시되지 않음
마이크음성으로 지출 입력(버튼을 누른 순간에만)음성 입력만 사용 불가
인터넷AI 모델·금리 목록 내려받기AI 기능과 금리 목록만 사용 불가

권한은 안드로이드 설정에서 언제든 철회할 수 있습니다.

3. 외부 서비스

앱은 아래에서 데이터를 내려받기만 하며, 이용자 정보를 보내지 않습니다.

  • GitHub — AI 모델 파일 및 금리 목록 파일 배포(HTTPS)
  • 금융감독원 금융상품통합비교공시 — 예·적금 금리 공시 자료. 개발자가 공시 자료를 수집해 파일로 배포하며, 이 과정에 이용자 정보는 포함되지 않습니다.

앱에는 광고 SDK와 사용자 행동 분석 SDK가 포함되어 있지 않습니다.

4. 보관 및 파기

  • 모든 데이터가 이용자 기기에만 있으므로, 앱을 삭제하면 함께 삭제됩니다.
  • 개발자가 별도로 보관하는 사본은 없습니다.
  • 앱 안에서 개별 데이터를 직접 삭제할 수 있습니다.

5. 아동 보호

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

6. 이용자 권리

데이터가 기기에만 저장되므로 열람·수정·삭제를 이용자가 앱 안에서 직접 수행할 수 있습니다. 개발자에게 별도로 요청할 정보가 없습니다.

7. 안전성 확보 조치

  • 데이터는 안드로이드가 제공하는 앱별 저장 공간에 보관되어 다른 앱이 접근할 수 없습니다.
  • 앱의 모든 네트워크 통신은 HTTPS로 암호화됩니다.

8. 방침 변경

이 방침이 변경되면 앱 업데이트와 이 페이지를 통해 공지합니다. 중요한 변경은 앱 안에서도 안내합니다.
